# ЛР1 — «Столик»

Адаптивный сайт бронирования столиков: поиск по названию, кухне, району и цене; карточка ресторана с меню и отзывами; вход, регистрация, личный кабинет и форма бронирования. Вёрстка выполнена на HTML, CSS и Bootstrap 5. Модальное окно, фильтрация и демонстрационное хранение данных работают на JavaScript.

Откройте `index.html` в браузере. Данные ЛР1 хранятся в `localStorage`: авторизация здесь демонстрационная и не предназначена для реальных аккаунтов.
