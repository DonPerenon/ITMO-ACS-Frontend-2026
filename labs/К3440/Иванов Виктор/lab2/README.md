# ЛР2 — взаимодействие с API

Продолжение ЛР1. Рестораны загружаются через `fetch` из JSON-сервера. Регистрация и вход выполняются через HTTP; пароль хранится на сервере как хеш с солью. Бронирования доступны только своему пользователю по токену.

1. Выполните `npm install` и `npm start` в этой папке. API будет на `http://localhost:3001`.
2. В другом терминале запустите `python3 -m http.server 8000` из этой же папки.
3. Откройте `http://localhost:8000`.

`db.json` содержит демонстрационные данные. Зарегистрированные аккаунты и брони записываются в этот файл. Для сброса удалите записи из массивов `users`, `sessions` и `bookings`.
