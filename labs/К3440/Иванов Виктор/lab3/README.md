# ЛР3 — SPA на Vue

Приложение для бронирования столиков перенесено с ЛР1/ЛР2 на Vue 3. Используются Vue Router, компоненты страниц и карточек, composable для авторизации и HTTP-клиента, axios для работы с API. Поиск, регистрация, вход, бронирование и история работают через локальный JSON-сервер.

## Запуск

Выполните `npm install`, затем в двух терминалах:

- `npm run api` — API на `http://localhost:3001`;
- `npm run dev` — приложение на адресе, указанном Vite.

`npm run build` собирает приложение. Данные API находятся в `api/db.json`; созданные аккаунты и брони записываются туда. Это учебная авторизация, поэтому не используйте реальные пароли.
