# ДЗ4 — SVG-спрайт

Продолжение сайта из ЛР1 и ДЗ2–3. Шесть иконок (приборы, поиск, пользователь, календарь, звезда, адрес) собраны в `assets/icons.svg` и подключаются через `<use href="assets/icons.svg#имя">`. Все декоративные иконки скрыты от скринридера, а текст кнопок и ссылок сохранён.

Откройте `index.html` и `restaurant.html?id=1`. Для корректного отображения внешнего SVG-файла запустите локальный сервер: `python3 -m http.server 8000`.
