# ДЗ3 — темы через CSS-переменные

Продолжение сайта из ЛР1/ДЗ2. Две темы используют один набор семантических CSS-переменных; переключатель в шапке меняет атрибут `data-theme` и сохраняет выбор в `localStorage`. В тёмной теме отдельно адаптированы формы, карточки, модальное окно и кнопки.

Откройте `index.html` и переключите тему. После обновления страницы выбор сохраняется.
