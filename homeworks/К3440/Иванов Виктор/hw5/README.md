# ДЗ5 — npm и основы Vue

Самостоятельный небольшой проект на Vue 3. Команда `npm install` устанавливает зависимости, `npm run dev` запускает сервер разработки, `npm run build` собирает приложение. В нём есть компоненты карточки ресторана и плана встречи, props, событие выбора, `ref`, `computed` и `v-model`.

В `screenshots/components.png` находится снимок работающего приложения после выбора ресторана. Код компонентов находится в `src/components/`.
