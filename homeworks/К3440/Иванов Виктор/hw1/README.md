# ДЗ1 — Flexbox, Grid и Git

Для сдачи нужен личный отчёт по [шаблону преподавателя](https://docs.google.com/document/d/1zgXRYAh9iO21NDcp5Cua3mOiNRWbAVZJBfgGiqGsMsU/edit?usp=sharing) с подтверждением прохождения:

1. [Flexbox Froggy](https://flexboxfroggy.com/#ru) — все уровни.
2. [Grid Garden](https://cssgridgarden.com/#ru) — все уровни.
3. [Learn Git Branching](https://learngitbranching.js.org/?locale=ru_RU) — первые четыре урока основного курса и все уроки раздела удалённых репозиториев.

После прохождения добавьте собственные скриншоты завершения игр в эту папку и экспортируйте заполненный отчёт как `Отчёт.pdf`. Отчёт не создан автоматически, поскольку он должен отражать фактическое прохождение заданий студентом.
